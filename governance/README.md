# Governance Records

This directory holds VIDS governance records. The governance model itself is defined in [GOVERNANCE.md](../GOVERNANCE.md) at the repository root; how to contribute is defined in [CONTRIBUTING.md](../CONTRIBUTING.md).

Contents:

- **MD-NNNN** files are Maintainer Decisions: short, durable records of governance and policy decisions. An MD is accepted when the required Steering Committee approval is recorded on its pull request and the pull request is merged. GitHub is the approval record.
- **CN-NNNN** files are change notes documenting notable validator or specification behavior changes.
- **REG-DOC.md** is a superseded artifact register, retained for history (see MD-0008).
- **TPL-MD.md** is the optional template for new Maintainer Decisions.

Numbering: use the next unused MD number when an MD is first added to a pull request; numbers are never reused.

Records are Markdown only. Rendered documents (PDF, docx) are not committed; CI enforces this.
